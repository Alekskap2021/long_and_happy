# Долго и счастливо — прототип сайта

Прототип по документу «Карта будущего сайта». Собран как система маршрутов
`ситуация → понимание → микроопыт → подходящий следующий шаг`, а не как каталог
курсов.

Стек: TypeScript, Next.js (App Router), React Query, Tailwind CSS v4, zod,
Base UI, lucide-react.

Визуальный язык, палитры, motion и правила вёрстки описаны отдельно:
[docs/design-system.md](docs/design-system.md).

## Запуск

```bash
npm install
npm run dev
```

Дальше `http://localhost:3000`. Проверка перед коммитом: `npx tsc --noEmit`,
`npm run lint`, `npm run build`.

## Как устроен код

### Контент как сущности, а не как страницы

`src/content` — единственный источник контента.

- `taxonomy.ts` — тема, формат, уровень (free/paid), вид продукта, статус
  публикации, плюс русские подписи для интерфейса.
- `schemas.ts` — zod-схемы всех сущностей: автор, материал, тема, продукт,
  диагностика, отзыв, блок главной.
- `data/*.ts` — сами фикстуры.
- `repository.ts` — доступ к контенту. Фикстуры валидируются схемами при загрузке
  модуля, поэтому расхождение данных и схемы падает сразу, а не в рантайме.

Переход на CMS меняет только реализацию функций в `repository.ts`: страницы
и компоненты про источник данных ничего не знают.

Черновики видны в коде, но не на сайте: `status: "draft"` исключает материал из
библиотеки и тему из списка опубликованных. Восемь из десяти тем заведены
черновиками — URL и таксономия готовы, страница включается сменой статуса.

### Три шаблона вместо уникальных страниц

- Тематический хаб (`/temy/[slug]`): живая сцена → бесплатный разбор → примеры →
  диагностика → связанные материалы → следующий шаг → маршрут в терапию.
- Продуктовая страница (`/kursy/[slug]`): ситуация → переопределение → для кого →
  кому не подойдёт → результат → метод → программа → авторы → границы → цена/CTA.
- Материал (`/besplatno/[slug]`): текст, блок «что дальше», связи с темой
  и продуктом, микроразметка Article.

### Блочная главная

`src/content/data/home.ts` — массив блоков с флагом `enabled`. Порядок задаётся
массивом, состав — флагом; страница `src/app/page.tsx` только перебирает блоки.
Реестр типов блоков — в `src/components/home/blocks.tsx`. Блок `boundaries`
выключен намеренно, как демонстрация механизма.

### React Query и API-слой

Контентные страницы серверные (SEO, быстрая отдача). React Query отвечает за
интерактив, и ходит он только в собственный API:

- `GET /api/materials` — библиотека с фильтрами и счётчиками фасетов.
- `POST /api/diagnostics/[slug]/result` — подсчёт результата диагностики.
- `POST /api/leads` — лист ожидания, запрос консультации, обращение.
- `POST /api/events`, `GET /api/events` — события воронки.

Клиентские вызовы собраны в `src/lib/api.ts`, ключи кэша — в
`src/lib/query-keys.ts`. Когда появится настоящий бэкенд или CMS, меняются
route handlers, а компоненты остаются прежними.

### Диагностика

Сценарий проходится по шагам в `src/components/diagnostic/diagnostic-runner.tsx`:
три ситуации по два вопроса — чего человек хочет и что делает словами.

Методика подсчёта живёт на сервере (`src/content/scoring.ts`) и считает
расхождение цели и способа, а также отдаёт подходящие следующие шаги. Отдельно
обрабатывается ответ с признаком небезопасности: тогда первым шагом
предлагается консультация, а не курс.

Ответы не сохраняются: сервер считает результат и возвращает его, ничего не
записывая. Это ограничивает аналитику осознанно.

### Аналитика маршрутов

`TrackFunnelStep` отмечает шаги: заход, просмотр темы, запуск и завершение
диагностики, просмотр продукта, заявка. События складываются в память процесса
(`src/server/store.ts`) и видны на `/sluzhebnoe/marshruty`. В продакшене это
место занимает внешняя аналитика.

### Палитры и переключатель темы

Восемь палитр: «Пауза» (по умолчанию), «Бумага», «Хвоя», «Пастель»,
«Сухоцвет», «Студия» и две тёмные — «Сумерки» и «Уголь». Каждая
переопределяет один и тот же набор смысловых токенов в OKLCH
(`src/app/globals.css`), реестр тем — `src/lib/themes.ts`.

Тема — это атрибут `data-theme` на `<html>`. Его ставит инлайн-скрипт до первой
отрисовки, поэтому вспышки чужой палитры нет; выбор хранится в `localStorage`,
а без сохранённого выбора берётся `prefers-color-scheme`. React читает атрибут
через `useSyncExternalStore`, то есть копии состояния нигде нет. Переключатель
(Base UI `Select`) стоит в шапке и подвале, превью палитр в нём рисуются
токенами, а не заданными цветами.

### Графика: иллюстрации и иконки

Иллюстрации — вектор на токенах палитры (`src/components/ui/illustration.tsx`):
абстракция без лиц и надписей, которая меняет цвет вместе с темой. Смысловая
часть остаётся контентом — alt и подпись лежат в
`src/content/data/illustrations.ts`, а сущности (тема, материал, продукт,
диагностика) ссылаются на ключ через необязательное поле `illustration`.
Роли: `band` — полоса-передышка внутри длинного текста, `block` — иллюстрация
в колонке, `thumb` — узкая полоса-превью, `BackdropArt` — та же графика фоновой
плоскостью под контентом. Единственный растр на сайте — портрет авторов.

Иконки — `lucide-react` через слой `src/components/ui/icon.tsx`. Они размечают
типы контента, а не украшают текст: форматы материалов, виды продуктов, шаги
метода, рамка «границы». Имена иконок совпадают со значениями таксономии,
поэтому `<Tag icon={material.format}>` работает без таблицы соответствий.

### Доступность и движение

Контраст всех пар токенов проверен на всех палитрах, включая инвертированные
полосы: минимум — 4.5:1. Интерактив (меню, фильтры, диагностика, формы, выбор
палитры) построен на Base UI, поэтому клавиатура и screen reader работают
без ручной разметки ролей. Анимации — три приёма, все выключаются при
`prefers-reduced-motion`; без JavaScript контент виден полностью.

## Что в прототипе заглушено

- Оплата: `/oplata` показывает условия и неактивную кнопку, платёжный провайдер
  не подключён.
- Заявки и обращения складываются в память процесса, а не в базу или CRM.
  После перезапуска сервера список пустой.
- Методика мини-диагностики — рабочая заглушка; её место займёт авторская логика
  Вероники и Игоря.
- Тексты, цены, отзывы и профессиональные данные авторов — заготовки для
  обсуждения, а не финальные материалы.
- Видео представлено описанием без плеера.
- `robots` в метаданных стоит на `noindex`, чтобы прототип не попал в поиск.

## Чего сознательно не делали

Классического лендинга «мы психологи → курсы → купить», отдельного дизайна под
каждую тему, LMS, Telegram Mini App, сложного поиска, таймеров и искусственного
дефицита.
